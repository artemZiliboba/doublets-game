# Doublets Game

Браузерная игра в словесные превращения. React + TypeScript + Vite.

## Локальный запуск

Нужен Node.js LTS.

```powershell
npm install
npm run dev
```

Открой адрес, который покажет Vite (обычно http://localhost:5173).

## Игровые данные

Сначала в репозитории `doublets` запусти `python cli.py export-game`. Затем скопируй три созданных файла в `public/game-data/` этого репозитория:

- `levels.json` — утверждённые уровни;
- `words.json` — разрешённые слова;
- `manifest.json` — метаданные экспорта.

Пока этих файлов нет, приложение запускает **явно обозначенный демонстрационный уровень** «кот → код → год». Это не замена редакторскому каталогу.

## Проверки

```powershell
npm test
npm run build
npm run preview
```

Прогресс сохраняется в localStorage браузера. Сервер и аккаунт не нужны. Изменения вносятся через ветки и PR; слияние — вручную.
